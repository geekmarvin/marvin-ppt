# marvin-ppt

可编辑的 PowerPoint 制作与分层复刻。Marvin 的个人 Codex Skill，适用于定稿后的提案与作品集，也适用于从 16:9 参考图还原可独立编辑的 PowerPoint 对象。

## 安装

1. 安装官方 **ppt-master**，按上游说明准备运行环境。已在本机使用 ppt-master 的用户可以直接继续。 [ppt-master 安装说明](https://github.com/hugohe3/ppt-master#3-set-up)
2. 在 Codex 里输入下面这句话：

   > 用 $skill-installer 从 https://github.com/geekmarvin/marvin-ppt/tree/main/skills/marvin-ppt 安装这个 Skill。

3. 安装后新开一个 Codex 对话，用 `$marvin-ppt` 开始制作。

也可以在本仓库点击 **Code → Download ZIP**，解压后，将里面的 `skills/marvin-ppt` 整个文件夹复制到 Codex 的 `skills` 目录。Windows 默认位置是 `%USERPROFILE%\.codex\skills`。如果你自定义了 Codex 主目录，请复制到该目录下的 `skills`。

## 用法

> 用 $marvin-ppt 把这张 16:9 参考图复刻成可编辑 PowerPoint。补完整被盖住的底图，把需要单独改换的文字、形状和图片拆开。

> 用 $marvin-ppt 把这份已定稿的逐页文案做成可编辑 PPT，保留文案和页序。

复刻时会按叠放效果和拆层后的效果验收。完全被遮挡的画面依据可见部分补绘，并在交付时说明。

个人规则见 [SKILL.md](skills/marvin-ppt/SKILL.md)。它独立安装，官方 ppt-master 可按官方说明单独更新。
